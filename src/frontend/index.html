      Quick Start Guide

      1. Load Knowledge Base

      Select a folder from the dropdown (top-left) and click "Load" to visualize your notes.

      2. Navigation

      • Pan/Zoom: Drag background to move, Scroll/Pinch to zoom.
      • Inspect: Click (Mobile) or Hover (PC) a node to see connections.

      3. Focus Mode

      Double Click a node to enter Focus Mode. This isolates the concept and arranges its dependencies hierarchically.

      4. Controls

      • Freeze (❄️): Stop movement to easily click/read nodes.
      • Layout: Switch between "Force" (Cluster) and "DAG" (Tree) layouts in the side panel.
