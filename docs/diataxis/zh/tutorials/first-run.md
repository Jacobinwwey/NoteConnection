# 教程：首次运行

本教程用于帮助新用户完成第一次启动和基础图谱加载。

## 步骤 1：启动应用

可选方式：

1. 使用桌面安装包。
2. 使用 `npx noteconnection`。
3. 本地源码运行（`npm install` 后执行 `npm start`）。

## 步骤 2：选择知识库

1. 打开数据源选择器。
2. 选择 `Knowledge_Base` 目录。
3. 点击 `Load`。

## 步骤 3：探索图谱基础能力

1. 在 `Force` 与 `DAG` 布局间切换。
2. 选择节点进入专注模式。
3. 打开节点对应的阅读内容。

## 步骤 4：进入 Path Mode

1. 点击 `Path Mode`。
2. 在桌面运行时确认窗口切换行为符合单窗口规范。
